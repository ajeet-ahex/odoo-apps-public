Stock Partial Transfer by Product Selection

Select products to transfer now, rest go to backorder automatically

Overview

This module adds a "Transfer" checkbox in stock picking operations. You can choose which products to transfer immediately, while unselected ones are automatically moved to a backorder using Odoo's native flow.

Supported: All Transfers

Key Features

  • Select specific products to transfer
  • Automatic backorder for unselected products
  • Works with Odoo's native backorder wizard
  • Handles partial quantities (shortages)
  • No impact on accounting or valuation
  • Lightweight and fast implementation

How It Works

Product Demand Done Transfer Result
Wireless Mouse 10 10 ✔ Transferred
Keyboard 5 0 ✘ Backorder
USB Cable 20 12 ✔ Partial + Backorder
  • All selected → Normal transfer
  • None selected → Normal transfer
  • Partial selection → Backorder created

Compatibility

  • Odoo 19 Community & Enterprise
  • Works with sale_stock
  • Works with purchase_stock
  • Works with mrp
  • Works with landed costs

Installation

  1. Copy module to addons folder
  2. Restart Odoo
  3. Update Apps List
  4. Install the module

Usage

  1. Open a transfer
  2. Go to Operations tab
  3. Select products using checkbox
  4. Enter quantities
  5. Click Validate
  6. Backorder will be created automatically
